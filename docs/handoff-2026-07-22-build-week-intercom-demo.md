# Codex Handoff Pack: Build Week 仮想インターホン

## Outcome

- Status: 実装、自動検証、PC・スマートフォンUI QA完了。独立レビュー前のドラフト。
- Goal addressed: ソフトウェアMVPの音声会話を維持したまま、実際のインターホンで話す体験を来訪者用UIで再現する。

## Changes Made

- 来訪者画面をアプリ型レイアウトから物理インターホン型の全画面体験へ変更した。
- 待機、通話、STT、LLM、TTS、最終再生、終了、障害を端末画面・波形・状態灯・ボタンで表現した。
- 技術情報、会話ログ、デモシナリオ、テキスト代替入力、手動音声再生、終了操作を `デモ情報` パネルへ分離した。
- 来訪者の初期画面からAI、STT、LLM、TTS、文字起こしを隠し、デモ情報を開いた場合だけ確認できるようにした。
- 既存の半二重録音、音声重複防止、最終音声再生待機、居住者への完了後通知ロジックは保持した。
- 390px幅では端末が一画面に収まり、デモ情報は全幅パネルになるようレスポンシブ化した。
- 通話中にテスターが即座にセッションを完了できる `テストを終了` ボタンを端末右上へ追加した。強制終了時は追加のAI応答やTTSを生成せず、取得済み内容だけで履歴と通知を1回確定する。
- Fish Audio `s2.1-pro-free`のまま、公開日本語音声の女性・男性を居住者設定とデモ情報パネルから切り替えられるようにした。選択はSQLiteへ保存し、次のAI応答から反映する。
- 男性の既定話者を、落ち着いたナレーション音声から、明瞭で自信があり玄関越しでも聞き取りやすい公開日本語男性音声へ変更した。
- Desktop / mobileのコンセプト画像とfidelity ledgerを追加した。

## Verification

- `npm run check`: lint、型検査、89テスト、本番buildがすべて成功。
- デスクトップ 1440 × 1000: 待機画面、プレゼンターパネル、呼び出し、宅配シナリオ送信、終了、居住者通知を確認。
- スマートフォン 390 × 844: 待機画面、全幅プレゼンターパネル、強制終了を確認。横スクロールなし。
- 両viewportでブラウザconsole error/warnは0件。
- TTS自動再生失敗時の手動再生、同一応答の重複再生防止、最終応答中に新規呼び出しを許可しない既存テストを更新後も通過。
- 新UIとAPIを同じ作業ツリーから `127.0.0.1:4173` / `127.0.0.1:8787` で再起動し、Vite依存キャッシュを再生成した。
- 実Groq、Gemini、Fish Audio構成で配達発話を1ターン処理し、文字起こし、`delivery / low` 判定、自然文応答、Fish音声生成まで成功した。
- 強制終了APIで `completionReason: tester_forced`、追加応答なし、完了済み履歴と通知1件への確定を確認した。
- 居住者画面で女性→男性へ変更し、来訪者デモ情報にも男性選択が同期されることを確認した。
- 男性設定で実Fish Audio APIから開始音声MP3が生成されることを確認した。
- 新しい明瞭な男性話者で開始音声「はい。ご用件をお伺いします。」を実生成し、2.246秒・35,943 bytesのMP3として取得できることを確認した。
- 390 × 844のデモ情報パネルで音声選択が見切れず、`scrollWidth === clientWidth === 390`、console error/warn 0件を確認した。

## Failures Or Skips

- 自動ブラウザQAではマイク権限を取得せず、音声入力はテキスト代替シナリオで確認した。
- 実プロバイダーによる1ターンの疎通は確認したが、複数シナリオでの主観的な応答品質と遅延は再計測していない。
- 男性・女性それぞれの声質の最終選定は未受入。公開音声の提供状態と利用条件は製品公開前に再確認する。
- 実装run自身では受け入れず、Coreまたは別Codex runによる差分・実音声レビューが必要。

## Assumptions

- 来訪者用Web画面はBuild Weekの体験再現と開発診断に使い、実製品では画面を提供しない。
- デモ情報はハッカソン審査時に処理の見える化が必要な場合だけ開く。
- 居住者画面、サーバーAPI、プロバイダー設定、SQLiteスキーマは今回変更しない。
- 強制終了を識別するため、既存終了APIの理由に `tester_forced` を追加する。DBスキーマ変更はない。

## Rollback

- `VisitorIntercom.tsx`、`PresenterPanel.tsx`、`styles.css`、終了理由の型・API・サービス、関連テスト、Build Week用デザイン文書をこの変更前へ戻す。
- DB、環境変数、外部API、統合用リポジトリへの変更はない。
