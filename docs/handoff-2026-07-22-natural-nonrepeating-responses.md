# Codex Handoff Pack: 自然な非反復応答

## Outcome

- Status: 実装・自動検証・Tailscale経由の実Gemini会話まで完了。独立レビュー前のドラフト。
- Goal addressed: 対応方針確定後に同じ定型文を何ターンも繰り返さず、来訪者の返答に応じて自然に会話を閉じる。

## Changes Made

- 通常応答はGemini生成を優先し、配達・お断り・再訪依頼等はサーバー側で意味と禁止事項だけを検証する構成を維持した。
- 直近4件のAI応答と文字bigram類似度を比較し、同一または高類似の生成文を再利用しないようにした。
- 単一の`followUpFallbacks`を、重複していない候補を選ぶ安全な応答プールへ変更した。
- 配達設定ごとの安全フォールバックも複数候補化し、必要な意味を保持したまま言い換えるようにした。
- 了承、別れ、安全な質問は、高リスク判定が履歴に残っていても確定済み方針を変えず短い自然な応答を許可した。
- Geminiプロンプトへ、了承・質問・反論・新しい用件の扱いと、過去のresponseを再利用しない規則を追加した。
- 開始挨拶、身元質問の回避、プロバイダー障害などの安全境界は決定論的な文言を維持した。

## Verification

- `npm run check`: lint、型検査、79テスト、本番buildがすべて成功。
- 重複したモデル応答を別の安全表現へ切り替えるテストを追加した。
- 高リスク訪問を断った後の了承に、短い文脈的な終了応答を保持するテストを追加した。
- 実Geminiで営業訪問に「あいにくですが、そのようなご案内は遠慮させていただきます。申し訳ございません。」と応答した。
- 続けて「わかりました。失礼します。」と入力すると、同じお断りを繰り返さず「はい、恐れ入ります。失礼いたします。」と応答して終了した。
- 最終音声の再生待機後に終了画面へ移り、ブラウザconsole error/warnは0件だった。

## Failures Or Skips

- ブラウザ自動操作環境ではマイク権限がないため、実会話はテキスト代替入力を使用した。GeminiとFish Audioの実API経路は動作した。
- 配達、通常来客、反論を3回以上続ける実ブラウザケースは今回未実施。単体テストで安全フォールバックを確認した。
- 実装run自身では受け入れず、Coreまたは別Codex runによる差分・実音声確認が必要。

## Assumptions

- 文字bigramのDice係数0.82以上を高類似と扱う。
- 比較対象は直近4件とし、古い応答まで避けて不自然になることを防ぐ。
- 安全候補は通常経路ではなく、生成文が禁止事項、長さ、必須意味、反復検査に落ちた場合だけ使用する。
